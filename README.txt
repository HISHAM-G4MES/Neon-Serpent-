NEON SERPENT - website package
Upload the whole folder (index.html, manifest.json, sw.js, icon-*.png) to any static host:
  * Netlify Drop (app.netlify.com/drop)  - drag the folder, get a link instantly
  * GitHub Pages / Firebase Hosting (Google) / Cloudflare Pages
It must be served over HTTPS (all of the above are).
PC: just open the link. Phone: Chrome menu > "Add to Home screen" (installs as an app).
Android APK: paste your site link into pwabuilder.com > Android.
Notes: progress saves in the browser (localStorage). Online and LAN modes were removed; Classic and Blitz work offline.
